What it does

Order, applied without guesswork.

Point Taneleer at the collection you already have. It reads, converts and proposes. You confirm. Nothing is written to your source files, ever.

Ingest

CBZ, CBR and PDF

CBR and PDF are converted to CBZ on entry. No system unrar, no PDF binaries. Large PDFs are read from disk, not memory. Existing ComicInfo.xml is preserved.

Enrich

ComicVine matching

Candidates are ranked on series, issue, volume, year and a cover fingerprint, and shown with the publisher, volume and issue count that tell relaunches apart.

Control

Fills and overwrites

Empty fields are filled. Existing values change only where you tick them. Your data is trusted until you say otherwise.

Organise

Path templates

Choose a preset or write your own: {Series}/{Series} #{Number} ({Year}).cbz, with a live preview.

Automate

Three auto-apply tiers

Manual, Assisted or Aggressive, with a tunable threshold. Files with existing metadata are never applied silently.

Integrate

Komga, kept in step

A scan is triggered on Komga after every confirmation. Optional watch mode rescans the source library for you.

Resolve

A whole run at once

When one volume matches many files, Taneleer pairs each file with its issue and confirms them together, showing which pairings need a look.

Bulk

Known matches, topped up

Files already carrying a ComicVine ID are checked and confirmed in bulk. Missing publisher and volume details on confirmed files are filled in.

Reversible

Every batch can be undone

Confirmed a batch in error? One button puts all of its files back in pending, exactly as they were. Any file you have changed since is left as it is, and you are told which.

The matching

Filenames lie. Taneleer checks.

Every issue is read carefully, ranked in two passes, and verified against its cover. The working is always shown, so a confident match and a lucky one are never confused.

  1. 01 · Parse

    Read the filename properly

    Year, volume and issue number are extracted from any common pattern. trees001 becomes series trees, issue 1. Jammed names such as seventoeternity are word-segmented before ComicVine is asked. A collected edition named for its volume, such as wickedplusthedivine_vol3, is paired with issue 3 of that volume.

  2. 02 · Rank

    Score every candidate on text

    Series names are compared by token similarity, ignoring case and diacritics, with & and + read as and and plus. The issue number must match exactly; where a file has none, as with collected editions, the volume tag and year count for more. An undated foreign reprint ranks below the original.

  3. 03 · Verify

    Compare the cover itself

    The leading candidates have their covers fingerprinted and compared to your file’s cover, by perceptual hash. It raises confidence; it never disqualifies, because variant covers are common and a different cover is not a wrong issue. Each candidate is labelled matches, similar, differs or not checked. The same fingerprints also find visual duplicates across your collection.

  4. 04 · Show

    Every score, itemised

    Each candidate carries its score, a per-signal breakdown, and the publisher, start year and issue count of its volume, so you can see precisely why it ranks where it does and which run of a title it belongs to.

Where the filename is hopeless, you teach Taneleer once. Aliases fold your own naming to a canonical series by prefix or regex. Resolve a run pairs every pending file of a series with its volume in one step, so a long series costs one decision, not twenty.

The method

Four steps. One queue.

  1. Scan

    Taneleer walks the source library and converts new files into a pending queue, live.

  2. Review

    Each file shows its cover, parsed filename and ranked ComicVine candidates.

  3. Confirm

    See exactly which fields fill and which differ. Confirm, and the next file appears.

  4. Collect

    The file is written to the output library at its template path. Komga reads it from there.

Safe by construction

Your source library is read-only.

Two directories, one pipeline. The source is never modified or deleted from. Taneleer produces its output elsewhere, and the output is always a valid input, so a round trip is safe.

PendingConfirmedCompromisedSkipped

Every file carries one of four statuses. Nothing is called Confirmed without a ComicVine match, and every state change is shown twice: on the item and in the tab counts.

Duplicates are found by cover fingerprint. Jammed filenames such as seventoeternity are folded to their series by alias rules. Re-enrichment of a confirmed file is always a manual act.
